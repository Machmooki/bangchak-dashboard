# System Folder

This folder contains the dashboard source app.

- `app/` - FastAPI app, Excel services, and static dashboard UI
- `tests/` - service tests
- `run_dashboard.py` - starts the local server and opens the browser
- `build_portable.py` - creates the Windows portable package
- `requirements.txt` - Python dependencies

Most users should start the dashboard from the project root with:

```text
..\Run Dashboard.bat
```

Portable output is created in:

```text
dist\Dashboard Bangchak\
```
